SQL Core

Structured Query Language। রিলেশনাল ডাটাবেস পরিচালনা, কুয়েরি করা এবং ডেটা বিশ্লেষণের আন্তর্জাতিক প্রমিত প্রোগ্রামিং ভাষা।

Database Concept

সুনির্দিষ্ট নিয়মে সাজানো ডেটার সুসংহত ইলেকট্রনিক ভাণ্ডার। রিলেশনাল ডাটাবেসে তথ্য টেবিল আকারে সংরক্ষিত থাকে।

Table Structure

নির্দিষ্ট সংখ্যক কলাম (Attributes) এবং সারি (Rows) নিয়ে গঠিত রিলেশনাল ডাটাবেসের মৌলিক দ্বি-মাত্রিক কাঠামো।

Row / Record Structure

একটি টেবিলের একক আনুভূমিক এন্ট্রি, যা একটি নির্দিষ্ট ব্যক্তি, বস্তু বা বিষয়ের পূর্ণাঙ্গ তথ্য ধারণ করে।

Column / Attribute Structure

একটি টেবিলের উল্লম্ব অংশ যা নির্দিষ্ট ডেটা টাইপের সমজাতীয় বৈশিষ্ট্য ধারণ করে (যেমন: first_name, ex_age)।

Query Core

ডাটাবেস থেকে তথ্য খোঁজা, ফিল্টার করা বা বিশ্লেষণ করার উদ্দেশ্যে SQL ভাষায় লেখা আনুষ্ঠানিক নির্দেশ বা স্টেটমেন্ট।

Schema Structure

একটি সম্পূর্ণ ডেটাবেসের সামগ্রিক নকশা, টেবিলসমূহের পারস্পরিক সম্পর্ক, কলামের নাম, ডেটা টাইপ এবং কনস্ট্রেইন্টের কাঠামোগত ব্লুপ্রিন্ট।

SQLite Engine

একটি স্বয়ংসম্পূর্ণ, সার্ভারবিহীন, জিরো-কনফিগারেশন বিশিষ্ট সি-লাইব্রেরি ডাটাবেস ইঞ্জিন। এই কোর্সের কুয়েরিগুলো ব্রাউজারেই SQLite-এ চলে।

Primary Key Constraint

একটি টেবিলের প্রতিটি Row-কে অদ্বিতীয়ভাবে (uniquely) শনাক্তকারী কলাম। এতে কোনো ডুপ্লিকেট মান বা NULL থাকতে পারে না।

Foreign Key Constraint

একটি টেবিলের কলাম যা অন্য টেবিলের Primary Key-কে নির্দেশ করে, দুটি টেবিলের মধ্যে নির্ভরযোগ্য সম্পর্ক রক্ষা করে।

NULL Data

ডাটাবেসে missing, unknown বা unavailable value নির্দেশক বিশেষ মার্কার। এটি সংখ্যা শূন্য (0) বা ফাঁকা টেক্সটের সমান নয়।

SELECT Clause

টেবিল থেকে কোন কোন কলাম বা এক্সপ্রেশন আউটপুট আকারে ফিরিয়ে আনা হবে তা নির্ধারণ করার মৌলিক SQL স্টেটমেন্ট।

FROM Clause

কুয়েরিটি কোন টেবিল, ভিউ বা সাবকুয়েরি থেকে ডেটা সংগ্রহ করবে তা সুনির্দিষ্ট করার SQL ক্লজ।

WHERE Clause

নির্দিষ্ট লজিক্যাল শর্ত পূরণকারী একক সারিগুলো নির্বাচন করার জন্য ফিল্টারিং ক্লজ।

LIMIT Clause

কুয়েরির ফলাফলে সর্বোচ্চ কতটি সারি প্রদর্শিত হবে তা নির্দিষ্ট করার ক্লজ (যেমন: LIMIT 3)।

ORDER BY Clause

ফলাফলকে এক বা একাধিক কলামের মানের ভিত্তিতে ছোট থেকে বড় (ASC) বা বড় থেকে ছোট (DESC) ক্রমে সাজানোর ক্লজ।

GROUP BY Clause

এক বা একাধিক কলামের অভিন্ন মানের ভিত্তিতে সারিগুলোকে দলবদ্ধ করে প্রতি গ্রুপের জন্য সারসংক্ষেপ গণনার ক্লজ।

HAVING Clause

GROUP BY-এর মাধ্যমে প্রস্তুতকৃত গ্রুপগুলোর ওপর শর্ত আরোপ করে গ্রুপ ফিল্টার করার ক্লজ।

Aggregation Operation

একাধিক সারির ডেটার ওপর গণনামূলক কাজ সম্পন্ন করে একটি একক সারসংক্ষেপ মান (Summary value) তৈরি করার প্রক্রিয়া।

COUNT Aggregate

টেবিল বা গ্রুপের অন্তর্ভুক্ত মোট সারির সংখ্যা গণনা করার বহুল ব্যবহৃত অ্যাগ্রিগেট ফাংশন।

SUM Aggregate

কোনো নির্দিষ্ট সংখ্যাসূচক কলামের সমস্ত মানগুলোর মোট যোগফল নির্ণয়কারী ফাংশন।

AVG Aggregate

কোনো নির্দিষ্ট সংখ্যাসূচক কলামের বৈধ মানগুলোর গাণিতিক গড় (Average) বের করার ফাংশন।

MAX / MIN Aggregate

কোনো কলাম বা এক্সপ্রেশন থেকে যথাক্রমে সর্বোচ্চ (Maximum) এবং সর্বনিম্ন (Minimum) মান খুঁজে বের করার ফাংশন।

JOIN Relation

একাধিক টেবিলের মধ্যবর্তী সাধারণ কলামের সম্পর্কের ভিত্তিতে সংশ্লিষ্ট সারিগুলোকে পাশাপাশি একত্র করার SQL কৌশল।

INNER JOIN Relation

উভয় টেবিলেই শর্ত অনুযায়ী মিল থাকা সারিগুলোকেই কেবল ফলাফল টেবিলে যুক্ত করে; গরমিল থাকা সারি বাদ দেয়।

LEFT JOIN Relation

বাম পাশের টেবিলের সব সারি ফিরিয়ে আনে এবং ডান পাশের টেবিল থেকে কেবল ম্যাচিং সারি আনে; অমিল স্থানে NULL বসায়।

Self Join Relation

একটি টেবিলকে তার নিজের সাথেই ভিন্ন ভিন্ন অ্যালিয়াস দিয়ে জয়েন করার বিশেষ পদ্ধতি (যেমন সহ-প্রস্তাবকদের সম্পর্ক বিশ্লেষণ)।

Subquery Advanced

আরেকটি মূল SQL কুয়েরির ভেতর বন্ধনীযুক্ত অবস্থায় লিখিত অভ্যন্তরীণ কুয়েরি (Nested Query)।

Alias / AS Clause

কুয়েরির ফলাফলে কোনো কলাম বা টেবিলকে সাময়িকভাবে সহজ ও অর্থপূর্ণ নাম দেওয়ার বিশেষ কি-ওয়ার্ড।

Filtering Concept

বৃহৎ ডেটাসেট থেকে অপ্রয়োজনীয় রেকর্ড বাদ দিয়ে নির্দিষ্ট শর্ত অনুযায়ী কাঙ্ক্ষিত ডেটা আলাদা করার পদ্ধতি।

Sorting Concept

অক্ষর, সংখ্যা বা তারিখের ক্রমানুসারে ডেটাকে নির্দিষ্ট বিন্যাসে সাজানো।

Execution Concept

ডাটাবেস ইঞ্জিনে একটি SQL কুয়েরি প্রেরণ করে ফলাফল প্রক্রিয়াকরণ ও আউটপুট পাওয়ার সামগ্রিক প্রক্রিয়া।

Result Set Output

কোনো SQL কুয়েরি সফলভাবে সম্পন্ন হওয়ার পর ডাটাবেস ইঞ্জিন যে টেবিল বা ডেটার সমষ্টি ফেরত পাঠায়।

Data Type Schema

কলামের মানের প্রকৃতি বা ধরন (যেমন: SQLite-এ TEXT, INTEGER, REAL, BLOB ও NULL)।

Constraint Schema

টেবিলের তথ্যের নির্ভুলতা ও নির্ভরযোগ্যতা বজায় রাখার উদ্দেশ্যে কলামের ওপর প্রযোজ্য বিধিনিষেধ (যেমন: NOT NULL, UNIQUE)।

Index Performance

ডাটাবেসে অনুসন্ধান কার্যক্রমের গতি উল্লেখযোগ্যভাবে বৃদ্ধি করার উদ্দেশ্যে তৈরি বিশেষ লুক-আপ ডেটা কাঠামো।
